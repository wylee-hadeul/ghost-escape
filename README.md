# 👻 귀신 학교 탈출

밤의 폐교에서 **귀신을 피해 열쇠를 모으고 탈출**하는 모바일 웹 게임. 친구와 **방 코드로 같이 플레이**할 수 있어요. Godot 4.6.

**플레이:** https://wylee-hadeul.github.io/ghost-escape/ (세로 화면 권장)

## 조작
- **이동:** 화면 아무 곳이나 터치 후 드래그 (PC: WASD/방향키)
- **달리기:** 오른쪽 아래 버튼을 누르고 있기 (PC: Shift) — 스태미나 소모, 발소리로 귀신이 온다
- **손전등:** 켜고 끄기 (PC: F) — 켜면 잘 보이지만 귀신에게 들키기 쉽다. 배터리 소모
- **숨기:** 사물함 근처에서 버튼 (PC: E)

## 규칙
- 층마다 흩어진 **열쇠를 모두 모으면 출구(계단)가 열린다** → 출구에 도착하면 탈출
- 생명 3개. **부적**은 귀신을 한 번 막아준다. **배터리**로 손전등 충전
- 미니맵에 탐험한 곳과 발견한 열쇠가 표시된다
- 스테이지가 오를수록 미로가 넓어지고 귀신이 많아진다. 폐교 → 폐병원 → 흉가

## 귀신
| 귀신 | 특징 |
|---|---|
| 처녀귀신 | 순찰하다 눈이 마주치면 추격. 놓치면 마지막 위치를 수색. 숨는 걸 보면 사물함까지 찾아온다 |
| 달걀귀신 (스테이지 2~) | 느리지만 벽을 통과해 다가온다 |
| 저승사자 (스테이지 3~) | 아주 빠르지만 손전등을 비추면 얼어붙는다 |

어둠 속에서는 귀신의 빛나는 눈만 보이고, 가까워지면 심장 소리와 붉은 경고가 나온다.

## 같이 하기 (코드)
1. 한 명이 **방 만들기** → 4자리 코드가 나온다
2. 친구들이 **코드로 참가** → 숫자 입력 (최대 4명)
3. 방장이 **시작!**
- 열쇠는 팀이 함께 모으고, 누구든 출구에 도착하면 모두 탈출
- 생명이 다 떨어지면 기절 → 동료가 옆에 2초 서 있으면 부활. 모두 기절하면 실패
- 브라우저끼리 직접 연결(WebRTC)하며, 처음 서로를 찾을 때만 PeerJS 공개 중계 서버를 사용. 일부 회사/학교 네트워크에서는 연결이 안 될 수 있음

## 개발
```bash
godot --path .                                                         # 실행 (같이 하기는 웹에서만)
godot --path . -- --autoplay --shots=/tmp/s --duration=60              # 오토플레이 봇 + 스크린샷/로그
#  옵션: --fresh --god --stage=N --speed=N  /  웹: index.html?autoplay&host=1234 , ?autoplay&join=1234
./tools/export_web.sh                                                  # 웹 빌드 (+ PeerJS/net.js 주입, 캐시 무효화)
```
구조: `level.gd`(미로 생성/A*/그림자), `ghosts.gd`(귀신 AI), `run.gd`(규칙/동기화), `net.gd` + `web/net.js`(연결)
